# Monotone valuations with at most three relevant goods (Theorem M3)

Workstream `proof/monotone-k`. Status: PROVED (written proof below; the one finite case analysis,
Lemma S3, is also checked exhaustively by `monotone/k3_check.py`).

## Setting

Agents N = [n], goods M = [m]. A valuation v_i : 2^M → ℝ≥0 is *normalized* (v_i(∅) = 0) and *monotone*
(S ⊆ T ⟹ v_i(S) ≤ v_i(T)). Good g is *relevant* to i if v_i(S ∪ {g}) > v_i(S) for some S. With R_i the
set of relevant goods, monotonicity gives v_i(S) = v_i(S ∩ R_i) for every S. (Remove the irrelevant goods
of S one at a time; each removal leaves the value unchanged.) The instance is *k-limited* if |R_i| ≤ k for
every i. EFX₀ is the raw all-goods notion: for all i ≠ j and every g ∈ X_j, v_i(X_i) ≥ v_i(X_j ∖ {g}).

A valuation is *nondegenerate on R* if v(S) = f(S ∩ R) with f injective on 2^R. With monotonicity this
makes f strictly increasing under inclusion, and every good of R is relevant. (This is the paper's term,
arXiv 2604.18216v4 §2.)

## Theorem M3

Every instance with normalized monotone valuations in which every agent has at most three relevant goods
has a complete EFX₀ allocation.

Consequently the smallest k at which monotone EFX₀ can fail is at least 4. It is at most 8 by the
three-agent, eight-good instance of Akrami et al. (arXiv 2604.18216v4, Theorem 3.4), in which every agent
values all eight goods (`monotone/amm_check.py`).

## Proof

**Step 1 (nondegenerate profiles suffice).** Fix n, m and the sets R_i with |R_i| ≤ 3. For agent i, list
R_i as g_1, …, g_r and put w_i(S) = Σ_{g_t ∈ S ∩ R_i} 2^t. Then w_i is injective on 2^{R_i}, additive and
strictly increasing. For ε > 0 let v_i^ε = v_i + ε w_i. It is normalized and monotone, depends only on
S ∩ R_i, and is injective on 2^{R_i} except for finitely many ε: v_i^ε(S) = v_i^ε(T) with S ≠ T forces
ε = (v_i(T) − v_i(S)) / (w_i(S) − w_i(T)). Take ε_t → 0 avoiding those values. If every v^{ε_t} has a
complete EFX₀ allocation, some allocation X occurs for infinitely many t, since there are finitely many
allocations. Each inequality v_i^{ε_t}(X_i) ≥ v_i^{ε_t}(X_j ∖ {g}) passes to the limit, so X is EFX₀ for v.
So it suffices to treat profiles in which every v_i is nondegenerate on its R_i, with |R_i| ≤ 3.

**Step 2 (Lemma S3: an additive surrogate).** Let v be nondegenerate on R with |R| = r ≤ 3. Then there is
an additive w with natural-number values, w(g) > 0 exactly for g ∈ R, such that for all *disjoint*
A, B ⊆ R:   v(A) < v(B) ⟺ w(A) < w(B).

*Proof.* Rank the singletons by v: s_1 > s_2 > s_3 (they are distinct because v is injective). Put
w(s_1, s_2, s_3) = (4, 3, 2) if v({s_1}) < v({s_2, s_3}) and (6, 3, 2) otherwise. For r = 2 put
w(s_1, s_2) = (2, 1); for r = 1 put w(s_1) = 1; r = 0 is trivial. Now take disjoint A ≠ B in R. Equality
A = B with A, B disjoint means A = B = ∅, where both sides are 0.
- One of A, B is empty: the other is nonempty, and both v and w are positive on it (v is strictly
  increasing).
- Two singletons: both v and w order them by the ranking.
- A singleton {x} and a set Y of two goods (so r = 3, Y = R ∖ {x}). If x ≠ s_1, then s_1 ∈ Y and
  v(Y) > v({s_1}) > v({x}) by strict increase. Also w(Y) ≥ 4 > 3 ≥ w(x) (weights (4,3,2)) and
  w(Y) ≥ 6 > 3 ≥ w(x) (weights (6,3,2)). If x = s_1, both v and w put {s_1} below {s_2, s_3} exactly in the
  balanced case: 4 < 3 + 2 and 6 > 3 + 2.
- No other disjoint pairs exist in a set of at most three goods: two disjoint nonempty subsets have sizes
  (1,1) or (1,2) up to order.
`monotone/k3_check.py` confirms this on all 1 + 2 + 48 nondegenerate monotone orders with r = 1, 2, 3
(the linear extensions of the Boolean lattices), with 0 mismatches. ∎

**Step 3 (EFX₀ depends only on disjoint comparisons).** For any allocation X, agents i ≠ j and g ∈ X_j,
we have v_i(X_i) = v_i(X_i ∩ R_i) and v_i(X_j ∖ {g}) = v_i((X_j ∖ {g}) ∩ R_i). The two arguments are
disjoint subsets of R_i. Extend each surrogate w_i of Step 2 by 0 outside R_i, so that w_i is additive with
relevant set exactly R_i. Then v_i(X_i) ≥ v_i(X_j ∖ {g}) ⟺ w_i(X_i) ≥ w_i(X_j ∖ {g}), because "≥" is the
negation of "<" and Step 2 matches "<" on disjoint pairs. So the EFX₀ allocations of (v_i) and (w_i) are
the same.

**Step 4.** (w_i) is an additive instance with natural-number values in which every agent has at most
three relevant goods. TARGET (ledger row T, PROVED; machine-checked over ℕ as `EFX.target`) gives it a
complete EFX₀ allocation, which by Step 3 is EFX₀ for (v_i). With Step 1 this proves the theorem. ∎

## Remarks

1. **Algorithm.** For a nondegenerate profile, the surrogate needs each agent's ranking of its ≤ 3
   singletons and the single comparison v_i({s_1}) vs v_i({s_2, s_3}). That is at most 5 value queries
   per agent; then K3ALG (ledger K3.ALG) on (w_i) returns an EFX₀ allocation. For degenerate profiles the
   proof only shows existence. A tie-aware surrogate would need care: with ties, a relevant good can have
   v_i({g}) = 0, e.g. v(b) = v(c) = 0 < v(a) < v(bc). Then i holding ∅ does not envy {b} under v, but does
   under any additive w that is positive on b.
2. **Which project lemmas use only monotonicity** (checked by re-reading the proofs in `proofs/lemmas.md`
   and PROMPT.md §3). Read F1's threat θ_i(X_j) as max_{g ∈ X_j} v_i(X_j ∖ {g}). For monotone v_i it still
   has F1's three properties: it is 0 on singletons, it equals v_i(X_j) when X_j contains a good outside
   R_i, and θ_i(X_j) ≤ v_i(X_j). F2 (rotation) uses only these and the fact that the bundles are the same.
   - L2's peeling rules R1, R2 and the general peeling step: yes. They use only v_i(X_j) ≤ v_i(R_i ∖ P)
     ≤ v_i(P) for X_j disjoint from P, and that a singleton or a bundle worthless to j cannot be
     strongly envied by j.
   - L2c, serial dictatorship for k ≤ 2: yes; also machine-checked for monotone valuations as `MRDMono`
     in evanlin23/mrd-efx (`proofs/citations.md`).
   - L3, junk to an envy-graph source, with rotation of envy cycles: yes.
   - L6, components: yes.
   - L5, ordinality of cores: at k = 3 it holds for monotone agents through Lemma S3 (the T/P/B/C/E cases
     are identical). L8 (two own goods suffice): yes, at k = 3.
   - L1 (perturbation to positive values) and L4/L7/L11 (counting, cores) are structural or additive and
     are not needed here.
   - The k = 3 proof of TARGET itself (LB⁺) uses additivity through L5, and Lemma S3 is exactly what makes
     that harmless.
3. **Where the argument stops.** Lemma S3 fails for r = 4. The nondegenerate monotone order printed by
   `monotone/k3_check.py` has v(a) > v(b) > v(c) > v(d) but v({c, d}) > v({a, b}). Every additive w with
   w(a) > w(c) and w(b) > w(d) has w(ab) > w(cd). So 4-limited monotone instances are a strictly larger
   ordinal class than 4-limited additive ones. A proof of monotone EFX₀ at k = 4 would imply TARGET₄. A
   monotone counterexample at k = 4 would show that any proof of TARGET₄ must use more than the comparisons
   that monotone valuations can realise.
